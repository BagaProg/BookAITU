# Изменения бронирования

- Жёлтые кабинеты (unavailable: отключённый кабинет или запрет доступа студентам) доступны для прямой брони только роли admin. Для обычного пользователя сервер возвращает 403; кнопка бронирования отключена.
- Жёлтый цвет сохраняется для обозначения ограничения. API дополнительно возвращает bookable, учитывающий роль текущего пользователя.
- Если на время есть занятие или подтверждённая бронь, кабинет становится occupied; забронировать его повторно не может даже администратор.
- Бронирование и поиск интервала ограничены 08:00–22:00 по времени Астаны, для обеих ролей. Окончание ровно в 22:00 разрешено. Проверка есть в API, выборе времени, сохранённом интервале и странице подтверждения. Старую заявку вне этих часов нельзя одобрить.
- Порядок заявок студентов сохранён: pending до одобрения. Одобрение не обходит запрет студенческого доступа к жёлтым кабинетам.

Миграций БД и новых переменных окружения нет. Сохраните свои рабочие .env; они не включены в архив. Установите зависимости через npm ci --prefix backend и npm ci --prefix frontend, выполните npm run build, перезапустите сервер. Для Render используйте существующий процесс развёртывания.

Проверено: 80 backend-тестов, 5 frontend-тестов и production-сборка. Проверены обе роли, конфликт брони, обе причины жёлтого статуса и границы рабочего времени. Полный сценарий через рабочий Microsoft-аккаунт не выполнялся. Изменения в этом архиве не опубликованы на Render.
